From an idea to a print

From model to 3D print

A digital design becomes a physical object through a series of small, precise steps.

  1. 01 / DESIGN

    Build the model

    Design a 3D model in SOLIDWORKS.

  2. 02 / EXPORT

    Prepare the file

    Export the design as an STL or 3MF file.

  3. 03 / SLICE

    Set up the print

    Open the model in a slicer and choose print settings.

  4. 04 / CHECK

    Review the layers

    Slice the model and check how each layer will print.

  5. 05 / PRINT

    Make it real

    Send the finished file to the 3D printer.
